## 실제 결과와 해석

동결 코드·모델·입력·정답·기준으로 기존엔진을 BACKFILL 호출하고 외부 기록은 BACKTEST로만 저장했다. 새 모델/예측 엔진/승격 기준을 만들지 않았다. 결과는 명시적S1/S2/S3 모두0, S3 선행 성공0, 선행일수N/A다. 기존 연구S1 8개는 이번 예측 실적으로 세지 않았다.

기존 파서는 원문 사건 후보9개를 보존했지만 완전한 TARGET·기간·독립 공급 근거로 연결되지 않았다. CPU 연구 경로는 DISCOVERY_ONLY로 보존하고 자동S단계를 가린다. V4 pipeline도 후보의s_stage를UNKNOWN으로 두므로 EARLY를S3로 계산하지 않았다. 현재 명시적S3 출력 연결이 없다는 구현 한계를 그대로 기록했으며 평가 결과를 보고 알고리즘을 고치지 않았다.

실제2021정전은 이번 부분 입력 진단에서S3로 발견하지 못했다. 그러나 입력은 주로여름 수요·예비율 전망이고 결과는 겨울 한파다. 겨울의 독립 수요/적격 공급/동시 고장/기간 관계가 확인되지 않았다. 이 불일치를 무시해 정식 모델FN·Recall을 만들지 않았다. **정식 비교 분모0, Precision/Recall N/A**다. Negative0이므로 오경보율도N/A이며 FP0이라는 빈 합계를 무오경보 성능으로 주장하지 않는다. 원문 부족을 모델 누락과 섞지 않았다.
