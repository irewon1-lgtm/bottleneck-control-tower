## 1. 목적과 상위 계약

병목 뉴스가 나오기 전에 독립적인 수요·공급 선행 변화를 결합하여 향후 12~36개월의 적격 공급 공백을 먼저 후보화한다. 주가·투자수익률·자동매매는 제외한다.

BCT_OBJECTIVE_LOCK.md의 bct-objective-1과 원문 문장/hash를 변경하지 않는다. 이 문서는 기존 docs/v4/EXECUTION_PLAN.md의 정량 자료 강화 하위 계획이다. 기존 단계 번호와 완료 기록은 다시 번호 붙이거나 삭제하지 않는다. 혼동을 막기 위해 이번 남은 일에 Q1~Q7이라는 고정 식별자를 사용한다.

단일 실행 원장은 기존 docs/v4/PROGRESS.json이다. 별도 진행 원장이나 새 마스터 계획서를 만들지 않는다. Q 실행을 시작할 때 기존 JSON 필드를 유지하면서 quantitative_plan 하위에 plan_id, current_step, status, source_status, evidence_paths, next_action, blocked_dependencies를 추가한다. 기존 자동화 상태와 Q 단계 상태는 서로 덮어쓰지 않는다. 계획만 저장한 시점의 Q1은 NOT_RUN이다.

S1/S2/S3는 기존 의미와 판정 기준을 보존한다. 단일 문서 S3·합성 S3·compare_gap 반환과 실제 forecast_discovery의 선행 후보 등록을 혼동하지 않는다. 선행 성공은 기존 Objective Lock의 독립 근거·공개일·최초 후보 기록·최초 병목 확인일 조건으로 검증한다.

## 2. 재검토 후 확정한 설계

기존 RSS/공식 색인 → 공통 수집기 → 출처별 JSON·CSV·XLSX·공시 본문 파서 → 수치와 단위·기간·개정 이력 저장 → 사건/제품/지역/고객별 연결 → 적격 수급 및 시점 비교 → 독립 성능 검증 → 검증된 경로의 자동화 → 실제 운영 검증 → 승인 후 전환.

기업마다 수집 프로그램 3,700개를 만들지 않는다. 공시기관·통계기관·자료 형식별 연결기를 재사용하고 CIK·시설 ID·계약 ID·품목 코드를 인수로 넣는다. 다만 개별 기업이 공개하는 생산 슬롯·수율·고객 인증·납기·공장별 생산능력은 공통 통계가 대신하지 못한다. 필요한 기업의 공식 자료를 같은 연결기로 추가하고 사이트별 예외만 설정으로 관리한다. 기업/제품 목록은 우선순위이지 닫힌 허용목록이 아니다.

숫자를 네 계층으로 분리한다.
- 물리량: 대수, kg/톤, 배럴, MW/MWh, 웨이퍼, 생산시간. 제품·순도·용도·기간과 단위 정의가 필요하다.
- 금액: 계약금액, 수주잔고, CAPEX. 수요 신호가 될 수 있으나 물량으로 임의 환산하지 않는다.
- 지수/비율: 생산지수, 가동률, 재고비율. 산업 탐색용이지 특정 부품의 적격 공급량이 아니다.
- 직접 시점 제약: 납기, 예약 슬롯, 적격 가동 준비일과 필요일. 수치 물량이 부족하더라도 기존 엔진이 허용하는 시점 경로로 조사하며, 미확인 수량을 만들어 넣지 않는다.

CSV/XLSX/JSON의 숫자는 우선 결정론적 파서로 읽는다. CPU/언어모델은 자유문맥의 후보 추출을 돕지만, 모델 응답을 공식 숫자·정답으로 취급하지 않는다. 구조화 추출 품질과 AI 의미 판독 품질을 따로 측정한다.

|---|---|---|

| Q4 | 독립 판독 및 과거 선행성 평가 | 사용 이력을 확인한 동결 자료와 당시 공개 버전으로 평가. 제품/사건/수치 추출, 실제 forecast 선행성, 오경보, 누락을 분리. 합성·개발 재생으로 실제 성능을 대체하지 않음. 아래 최소 구성과 채택선을 결과 보기 전에 고정. |

기존 순서와의 대응: Q1~Q2는 자료 확보/판독 보강, Q3는 수급 연결, Q4는 과거 평가, Q5는 전체 자동화, Q6는 7일 운영, Q7은 최종 전환이다. UI 재제작·전체 재설치·새 모델 탐색을 앞단에 끼워넣지 않는다.

### Q4 고정 최소 평가 구성과 제품 채택선

평가 입력은 당시 사용 가능했던 버전만 사용하고, 문서/사건/원출처 중복 및 개발 노출을 제거한다. 평가 엔진·입력 범위·정답·수치 변환·채점 기준을 먼저 고정한다. 다음은 이번 계획의 최소 채택선이며 달성한 성적이 아니다.

- 본 평가: 객관적으로 발생한 Positive 최소 5건, 발생하지 않은 Negative 최소 5건(그중 hard Negative 최소 3건). 별도 미사용 HOLDOUT 최소 3건은 병목 2건과 비병목 1건 이상을 포함한다. 뉴스 검색에 안 나온 것을 Negative로 만들지 않는다.
- 최소 선행성: 본 Positive 5건 중 최소 3건의 정당한 forecast 후보가 고정된 최초 공개 병목 확인보다 먼저 기록되어야 한다. Negative 5건에서 잘못된 최종 공급 공백 경보 0건, HOLDOUT 병목 최소 1건 선행 탐지 및 비병목 오경보 0건. 단순 S1·제품명 발견은 성공이 아니다. 더 큰 평가군은 전체를 공개하고 유리한 5건만 고르지 않는다.
- 같은 자료에서 비교 가능한 기존 경로 대비 오탐 감소·누락 악화 없음·근거 없는 사실 채택 차단이라는 기존 판독 도입 기준은 낮추지 않는다. CPU가 지원하지 않는 사건 역할을 CPU 성능 분모로 임의 채우지 않는다.
- AI 보조 정답 검토는 인간 검증으로 표시하지 않는다. 평가 이력이 확인되지 않으면 해당 평가만 BLOCKED다. 모델의 과거 사건 사전지식 오염 가능성을 별도로 밝히고 무오염이라고 주장하지 않는다.
- 이 최소 소표본 통과는 전 산업의 정확도 보장이나 LIVE 선행 성과가 아니다. BACKFILL과 LIVE 최초 발견은 별도 원장·표로 보고한다. 기존에 명시적으로 승인된 더 엄격한 기준이 있으면 함께 충족해야 한다.
- 합격선을 사후 완화하거나 결과를 보고 평가군/정답을 바꿔 재시험하지 않는다. 미달 후 수정은 개발 자료에서만 하고, 이미 공개한 평가 결과는 회귀 증거로 보존한다. 새 독립 평가를 자동 반복하는 루프는 금지한다.

## 4. 멈추지 않되 PASS를 남발하지 않는 규칙

진행 순서는 고정하지만 모든 산업을 직렬로 막는 전역 잠금은 만들지 않는다. 같은 단계에서 모든 산업을 공통 큐로 처리한다. 한 출처가 403/키 부족/본문 누락이면 그 출처와 그 근거에 의존하는 판단만 보류하고, 나머지 출처의 다음 독립 작업은 진행할 수 있다. 부족한 출처를 제외하고 전체 단계를 PASS라고 부르지는 않는다.

기존 승인된 RSS 자동수집 및 연구용 CPU 예약 활성화·관측은 별도 운영 작업으로 병행 가능하다. 이를 정량 확장 Q5/Q6 완료나 AI 품질 통과로 세지 않는다. 현재 변수가 실제로 변경됐는지는 실행 시작 시 확인하며, 이 문서가 자동화 ON을 의미하지 않는다. 새로운 출처의 예약 적용·처리량 증가·운영 승격은 Q5 안전 조건을 충족해야 한다.

기간별 원문 공개일과 데이터 관측월은 다르다. 오늘 받은 최신 개정 통계의 과거 값을 당시 알려진 수치처럼 소급 사용하지 않는다. 최초 관측 시점과 공개 시점이 불명확하면 과거 선행 평가에서는 보류한다.

전체 공급 정확치가 없더라도 검증 가능한 수요 하한/상한·공급 하한/상한 및 시점 제약을 보존한다. 공급 상한·전체 적격 공급 범위가 확인되지 않았는데 관측된 일부 공급만 빼서 부족 확정 금지. 알려진 공급=전체 공급으로 가정하지 않는다. MW↔MWh, 광석톤↔금속 함유량, 웨이퍼 투입↔양품, backlog 잔액↔신규 주문 흐름, 계약 총액↔증액 거래를 섞지 않는다.

정부 자료라고 모든 내용의 재배포·보관이 자동 허용되는 것은 아니다. 출처 이용조건·개인정보·기존 원문 분리 스키마를 유지한다. 보관 불명 원문 3건과 기존 연구 자료를 삭제/재복제하지 않는다. 공식 기계판독 자료도 허용되는 보관 범위와 근거 재조회 방법을 출처별로 등록한다. 해시만으로 원문 사실 재검증이 되었다고 말하지 않는다.

## 5. Q1의 고정 범위

출처군 8개: SEC EDGAR / Census M3 / Fed G.17 / USAspending / Census 품목별 무역 / EIA / USGS 광물 / EU TED.

8개는 연결 작업의 범주이지 8개의 독립 수급 증거라는 뜻이 아니다. USGS가 인용한 Census 무역값, FRED가 재게시한 Fed 값, 기사 재인용은 동일 원계보로 관리한다. Federal Register 등 기존 다른 연결기는 보존하며 필요한 규제 보강은 Q2에서 사용한다.

실제 구현은 STEP1_INSTRUCTIONS.md를 따른다. 출처 추가·숫자 변환·기간 변경은 manifest와 변경 사유를 남기되 단계 목표·기준을 묵시적으로 바꾸지 않는다. API 경로 폐지 시 같은 의미의 공식 대체 경로 연결은 유지보수이며 계획 변경이 아니다. 유료 전환·대상 의미·통과 기준 변경은 사용자 승인 대상이다.

## 6. 시작·종료·재개 형식

매 작업 시작: 실제 HEAD/미커밋 변경 확인 → Objective Lock → 기존 EXECUTION_PLAN/PROGRESS → 이 계획 → 해당 단계 지침 순으로 읽는다. 과거 SHA reset, 완료한 1,277창 재판독, 정상 Secret 재발급, UI 재제작을 하지 않는다. 계획 버전과 현재 Q단계를 보고한 뒤 구현한다.

매 배치 종료: 처리 완료 ID와 커서, 수치 검증 결과, 저장/복원 근거, 미처리/차단 원인, 다음 작업을 기존 PROGRESS 및 기존 실행 원장에 저장한다. 계획의 이름만 바꿔 새 작업으로 시작하지 않는다.

일반 보고는 현재 단계/실제 숫자 수와 물리량 수/출처별 범위/해결한 결함/남은 공백/정확한 SHA·실행시험/다음 작업으로 고정한다. 코드 줄 수·단위시험 수·URL 수가 핵심 목적 달성의 대용물이 될 수 없다.

## 7. 검토한 공식 자료와 의미 제한

- SEC: https://www.sec.gov/search-filings/edgar-application-programming-interfaces — Company Facts는 비표준 기업 고유 태그와 모든 생산·주문 문맥을 대체하지 못함. 공시 본문/첨부 병행.
- Census API 키: https://www.census.gov/library/video/2026/adrm/requesting-a-census-data-api-key.html — 현재 데이터 질의에 키 필요. 없는 키를 만들어 넣거나 안내 없이 호출 실패를 반복하지 않음.
- M3: https://www.census.gov/manufacturing/m3/current/index.html — 주로 금액 기반 주문/재고/출하.
- Fed: https://www.federalreserve.gov/releases/g17/download.htm — 지수/가동률과 일부 물량을 구분. DDP 변경 안내가 있으므로 안정된 공식 텍스트/CSV 경로 우선, 경로 수명 관리.
- EIA860M: https://www.eia.gov/electricity/data/eia860m/index.php — 예비 추정·사후 수정 및 설비명목능력이지 공급 확약은 아님.
- EIA API: https://www.eia.gov/opendata/documentation.php — 키·페이지·반환단위·값 표현 확인.
- USGS: https://www.usgs.gov/centers/national-minerals-information-center/tungsten-statistics-and-information — 품목별 공개빈도·단위·추정/비공개 표시를 유지.
- 무역: https://api.census.gov/data/timeseries/intltrade/imports/hs/variables.html — 수량/가치/운송중량 및 실제 0 플래그 구분.
- USAspending: https://api.usaspending.gov/docs/endpoints — 계약/거래 금액과 수정 이력, 물리량 보장 아님.
- TED: https://docs.ted.europa.eu/api/latest/search.html — 인증 없는 공개 공고 검색, 공고/낙찰/수정/취소 및 lot별 범위 구분.

위 자료는 계획 검토에 사용한 공식 문서다. 이 문서 작성 중 8개 출처의 실제 BCT 수집·저장 통합시험을 실행한 것은 아니다.
