## 보류 원인과 다음 데이터 취득 방향

1. `TARGET_FIELDS_UNKNOWN` 6건: 정확한 같은 제품·규격·지역·고객·적격 공급자 풀을 **원출처 본문과 locator**로 확보해야 한다. 다른 산업·규격의 공급량을 같은 TARGET으로 합치면 안 된다.
2. `CPU_ENTITY_ONLY_SEMANTICS_PENDING` 5건: 제품명 감지만으로는 수요·공급 이벤트가 아니다. 고객의 확정 주문 또는 공급자의 실제 적격 생산능력, 필요 시점·가용 시점을 담은 독립 원본이 필요하다.
3. **수요측**: 신규/증분 확정 주문, 품목·규격·지역·고객, 물량·단위·시점 근거. **공급측**: 별도 독립 발행자의 고객 적격 인증, 미예약 가용 생산능력, 증설 완료 예정 시점 및 공급 지역 근거.
4. 주문 보도자료 재인용·동일 원발행자·복사한 본문·같은 계약 반복 발표는 독립 근거로 세지 않는다. 반대 근거(충분한 적격 공급, 재고·대체 공급, 주문 취소/연기)도 확인해야 한다.
5. 원본 확보 전에는 대상 조건의 누락 수치를 `UNKNOWN`으로 유지하고, 0/미확인을 실제 공급 부족으로 읽지 않는다.
6. **외부 검색 제한**: 연구용 비공개 원문·파생 정보로 일반 검색어를 구성하지 않는다. 공개 원출처의 공개적으로 검증된 참조 또는 명시 승인된 원문 URL만 사용한다. 이번 검증은 검색·URL 재수집을 수행하지 않았다.

## 세션 5 완료 조건(남은 관문)

- 분석대상의 각 원출처 version·발행자·발행일·문서 해시 및 이벤트 구간이 검증되고, 별개 발행자의 실제 DEMAND/SUPPLY 사실이 같은 TARGET의 5개 차원에 묶이는지 감사한다.
- 누락 범위·적격 공급·기간·단위 비교 및 반대 증거를 결측값 보정 없이 검증한다.
- 후보가 없다면 **근거 없음/HOLD**로 정확히 분류하되 **적격쌍 탐색을 완료했다고 주장하지 않는다**. 후보가 있을 때는 2개 원본과 독립성을 확인한 뒤에만 다음 단계 후보로 이동한다.
- 11건 외 더 넓은 전체 기사 코퍼스의 처리 성공/미처리/보류 건수는 별도 실제 입력 실행과 저장 재조회로 검증해야 한다.
- 예측 적중률, 12–36개월 미래 병목 발견, 운영 공개 대시보드 갱신은 **아직 미검증**이다.
