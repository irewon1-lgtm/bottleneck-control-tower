- 장식·기업/조직명·일반 표현·동사·스포츠·출판물·주식 정보21개는 제품으로 채택하지 않았다. 예: NIST `Lock/padlock`, 작성자 약력의 `Science/soccer`, 회사 `Generate`, `Flying J`, `civils pipeline`.
