# 미래병목 수급 비교 v1

목적: 현재 부족하지 않은 세부 제품·공정·설비에서 앞으로 24개월 이내 생길 부족을 발견하고, 미국 상장 기업의 이익 귀속과 주가 선반영을 별도로 확인한다. 0~12개월과 12~24개월 모두 관찰한다. 부족 시점을 수요 성장·증설 예정일로 대체하지 않는다.

기존 `future-bottleneck-data/future-tracking.json`과 월·수·금 정기 조사만 이용한다. 새 API, DB, 점수, 워크플로는 만들지 않는다. `src/bct/supply_gap.py`는 검토된 입력을 비교하는 표준 라이브러리 함수다. URL이 있다고 사실을 검증한 것으로 보지 않는다. 조사자가 본문·대체 공급·범위를 확인해야 한다.

## 정기 조사

1. 최신 추적 파일을 읽고 다음 점검 대상 중 3~5개를 순환한다. 매 회차 일부는 소재·중간재·인증·생산장비·세부 공정의 새 후보 탐색에 쓴다. 기존 최대 10건 본문 제한을 유지한다. 기사 shortage 문구가 없어도 고객 계획·발주·인증·장기계약·증설 시점을 탐색한다.
2. 필요한 시점의 수요와 같은 규격·지역·고객에게 실제 인도 가능한 공급을 비교한다. 공급 상한에는 경쟁사·증설·재고·적격 대체재도 근거에 따라 반영한다. 한 공장 지연은 산업 전체 부족의 증거가 아니다.
3. 수량은 `최소 수요 - 최대 공급`부터 `최대 수요 - 최소 공급`까지 계산한다. 하한이 양수일 때만 범위 전반의 부족이 지지된다. 겹치면 조건부다. 숫자 비공개는 null이며 0이나 임의 가동률로 채우지 않는다.
4. 수량이 없어도 고객의 확정 필요일보다 모든 현실적인 적격 공급 경로의 가장 빠른 납기가 늦으면 일정 근거로 비교할 수 있다. 모든 공급 경로 확인이 안 되면 UNRESOLVED다.
5. '현재 부족하지 않음', 부족 발생 시점, 반증 점검까지 근거가 있어야 `FUTURE_MATCH`다. 부족 기사 미발견은 현재 공급 충분의 증거가 아니다. 이는 검토 범위의 판단이며 미래의 보장이나 전체 산업 누락률 측정이 아니다.
6. 병목 여부와 별도로 기업별 제품 매출·이익·가격전가·증설비용·계약 구조·희석, 현재 가치평가를 확인한다. 전문자료에 공개된 사실은 대중에게 숨겨졌거나 주가에 미반영됐다는 증거가 아니다. 투자 판단은 UNRESOLVED에서 시작하며 계산기가 매수/급등을 판정하지 않는다.

## 입력과 기록

각 의미 있는 TARGET 검토의 새 history 항목에 `comparison_inputs`와 `supply_gap`을 함께 저장한다. 기존 history, 고정 baseline, target ID를 덮어쓰지 않는다. 입력이나 중요한 판단 변화가 없으면 이력을 추가하지 않고 runs에 조회·오류만 남긴다. 근거가 없는 입력을 만들지 않는다.

`comparison_inputs`의 모든 근거 항목은 `basis`(해석과 계산 근거), `evidence` 배열을 쓴다. evidence는 실제 읽은 `url`, `published_on`, `locator`(페이지/문단)를 기록한다. 최신 리뷰의 근거만으로 판단하고 과거 가설의 결과는 별도 outcome에 기록한다.

- `current`: `state=NOT_SHORT|SHORT|UNRESOLVED`. 대상의 현재 공급 상태 근거.
- `shortage_window`: `start`, `end`(ISO 날짜). 예상 부족 발생 범위. 연구 편의상 날짜를 만들지 않는다.
- `demand`, `supply`: `min`, `max`, `scope`, `unit`, `period_start`, `period_end`, `balance_basis`. 양쪽은 정확히 같아야 한다. basis는 전체수요/전체공급(`total`) 또는 신규수요/미예약공급(`incremental_free`) 중 하나다.
- `supply`: 추가로 `kind=QUALIFIED_DELIVERABLE`, `coverage=ALL_FEASIBLE_SUPPLIERS`. 명목 생산능력·공장 준공·혼합 제품 매출은 적격 공급량이 아니다. 알려진 실제 및 예정 공급을 검토하되 계획·인증 미완료와 불확실성을 상하한에 명시한다.
- `timing`: `required_by`, `earliest_qualified_supply`, `coverage=ALL_FEASIBLE_SUPPLIERS`. 미확인 대체공급이 있으면 PARTIAL로 기록한다.
- `relief`: `review_complete`와 증설·대체재·재고·수요 지연 확인 근거. 공급량 계산에 중복 반영하지 않는다.
- `market_awareness`, `economic_capture`: `state`와 근거. 미확인은 UNRESOLVED다.

계산 예: `evaluate(comparison_inputs, reviewed_on)` 결과를 `supply_gap`에 저장한다. synthetic 테스트 입력을 실제 조사에 사용하지 않는다. quantity와 timing이 충돌하면 자동 승격하지 않는다. 기존 status와 목표 적합성은 별도로 보존한다.

성과: 미래 판정 당시 자료·발견일·예상 부족 기간을 보존하고, 해당 기간의 실제 납기·공급 부족/해소를 비교한다. 검증 가능 표본의 적중·기각·미도래를 분리한다. 과거 자료를 재생할 때 당시 공개 자료만 사용한다. 주가 성과와 병목 예측 성과는 별도 측정한다. 근거 없는 완성도%·정확도%를 붙이지 않는다.
