## 고정 운영 예산

기존 회차 본문 확보 최대 300문서, worker 6, 검토 묶음 최대 10문서·12,000문자를 유지한다.
묶음마다 최장 대기 1자리, 사전 미등록 TARGET 1자리를 확보한 뒤 명확한 주문/직접 공급 근거를 우선한다.
슬롯은 중복 배정하지 않는다. 7일 이상 대기는 먼저 FIFO 슬롯으로 처리하고 잔량을 모두 보존한다.
수동 검토가 없으면 예산 준수를 자동 완료로 간주하지 않는다.
같은 빈칸은 신규 근거 또는 명시된 인증·양산·평가 일정이 도래할 때만 재검토한다.
